# 素材库（library/）

免版权 BGM / 图片 / 视频片段的本地缓存目录（P7-1）。**用户自带文件永远优先**——
任务内 `output/<任务>/assets/` 里已有的素材不受库影响，本库只是"可复用地往任务里选用"。

## 目录约定

| 子目录 | 放什么 | 白名单扩展名 |
|---|---|---|
| `library/bgm/` | BGM 音乐 | mp3 wav m4a aac ogg flac mp4（与管线 `findBgm` 同表） |
| `library/images/` | 背景图 / 样机图 | jpg jpeg png webp |
| `library/clips/` | 视频片段（分镜 media 引用） | mp4 mov webm mkv |

## 怎么用

1. 把文件丢进对应子目录（首次打开网页面板时自动建目录）。
2. 网页底部「素材库」区点 ↻ 刷新 → 选目标任务 → 点选用。
3. 选用 = **复制**进 `output/<任务>/assets/`，之后到重跑表单跑对应步骤生效：
   - BGM → `assets/bgm.<ext>`（旧 bgm 会被替换），**从第 2 步重跑**（卡点检测 + 混音）；
   - 图片「作背景图加入」→ 自动编号 `bg-NN`，**从第 3 步重跑**；
   - 图片/片段「原名复制」→ 分镜 `shots.json` 里 media 按文件名引用，改分镜后重跑对应步。
4. 建任务时也可以在左侧表单「BGM」处直接下拉选用库内文件（与自带上传二选一，自带优先不冲突——同传报 400）。

## 规则

- 本目录内容**不进 git**（见根 `.gitignore`），只入库本说明；换机器时自行重新放入素材。
- 版权自审：只放自己有授权/免版权的素材；管线不做内容审查。
- 隐藏文件与白名单外扩展名不会出现在面板列表里（不报错，静默忽略）。
