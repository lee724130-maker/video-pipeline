# Skill · 画面方案（每镜的视觉决策）

原则：**字大、层级少、动效克制**。竖屏观看场景 = 单手持机、可能静音，
所以画面必须「不看字幕也能 get 到重点」。

## 一、设计令牌（`templates/base.css`）

- 背景：深色 `#0B0E14` → 径向光晕（青 `#08B6DD` / 紫 `#7C3AED` 二选一为主色）
- 主文字：`#F5F7FA`，权重 800；次文字：`#9AA3B2`
- 强调色：每片只允许一个（默认青，纯数字类内容用紫）
- 安全区：上下各留 180px（抖音界面会盖住底部、顶部有状态栏）

## 二、各类型模板的视觉职责

| type | 画面职责 | 允许动效 |
|---|---|---|
| title | 钩子大字 + 副标 | 入场位移+淡入，关键词逐字高亮 |
| bullet | 小标题 + 要点列表 | **要点随配音逐条出现**（时间由配音决定） |
| keyword | 一个大词 + 一行注解 | 缩放弹入 |
| transition | 章节序号 + 章节名 | 左→右扫入 |
| end | 收尾金句 + CTA | 淡入 + 呼吸感光晕 |

## 三、硬规则

1. **单屏信息 ≤ 7 行**（标题行不计）。
2. 正文字号 ≥ 44px（1080 宽画布），标题 ≥ 96px。
3. 动效总时长 ≤ 0.6s，且**必须在镜头时长的前 25% 内结束**，不要全程飘。
4. 每镜首尾各 0.15s 淡入淡出（模板已内置），保证硬切不刺眼。
5. 不用表情符号字体、不用第三方图标库（离线渲染会变豆腐块）。
6. 中文字体一律 `Microsoft YaHei`（本机已验证可被 hypit 无头浏览器渲染）。

## 四、新增模板的步骤

1. 在 `templates/scenes/` 新建 `<type>.html`，用 `{{TOKEN}}` 占位。
2. 在 `03-scenes.cjs` 的 `TEMPLATES` 里登记该 type 的 token 列表。
3. 在 `skills/script.md` 的 type 白名单加一行。
4. 跑一次 `node pipeline/run.cjs` 出样片，确认无豆腐块、无溢出。
