# Skill · 质检清单（成片必须过的关）

`pipeline/06-qc.cjs` 自动跑机械项；语义项由我看帧判断。全部通过才算交付。

## 一、机械项（脚本自动判定）

| 项 | 阈值 | 不过 = |
|---|---|---|
| 总时长与设计时长 | 误差 ≤ 0.35s | FAIL |
| 分辨率 / fps | 与 shots.json 一致 | FAIL |
| 音频流 | 存在、aac、时长 ≥ 视频 95% | FAIL |
| 平均响度 | mean_volume 在 -30 ~ -8 dB | WARN |
| 黑屏 | 连续黑帧 > 0.5s | FAIL |
| 字幕烧录 | 成片抽帧可见字幕像素差异 | WARN |

## 二、语义项（我抽帧/听音判断）

1. 首帧 3 秒内读到钩子；要点条数与口播一致；结尾 CTA 清晰。
2. 字幕不压安全区、不与画面主标题重叠。
3. 逐词字幕与口播对得上（抽 3 个时间点比对）。
4. 无豆腐块、无文字溢出画布。
